# Pink Pony Launcher - downloads

Download the latest `PinkPony-Setup.exe` from [Releases](https://github.com/Cooldownbro5/pinkpony-launcher-releases/releases/latest).
The launcher updates itself after that.

[Cooldownbro5/pinkpony-launcher](https://github.com/Cooldownbro5/pinkpony-launcher) (MIT)
